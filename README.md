# RPA Automation Portfolio

This repository showcases end-to-end RPA automation solutions built using Automation Anywhere and supporting tools.

## 📌 Projects

### 1. Invoice Processing Bot
Automates extraction of invoice data from documents and stores structured output in Excel with validation and error handling.

### 2. Employee Onboarding Bot
Automates HR onboarding tasks including folder creation, email notifications, and checklist generation.

### 3. Ticket Classification Bot
Classifies incoming support emails into categories and stores structured data for reporting.
